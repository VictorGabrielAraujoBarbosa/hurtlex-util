# 🧪 Hurtlex Util

A standardized, modular, and scientifically transparent text processing and NLP pipeline for our research group.

## 📌 Philosophy

In scientific research, reproducibility and transparency are more important than execution speed. This package is built on the principle of **explicit rules over implicit magic**. 

* **No Black Boxes:** Every function does exactly one thing and has a strict mathematical or logical definition.
* **No Hidden Variables:** Rules (such as lists of stopwords or allowed characters) must be explicitly passed by the researcher, ensuring that methodologies are perfectly clear for peer review.
* **Pure Functions:** Functions take an input, apply a transformation, and return an output without altering global states.
